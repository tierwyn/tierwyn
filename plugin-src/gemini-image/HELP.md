# gemini-image

## What it does

Writes an image generated by a Gemini 3.x image model into your artifacts shard and
returns `{ path, mime, bytes }`. It never returns image bytes and never exposes
`GEMINI_API_KEY`. Output is `image/png` or `image/jpeg`.

## Call

`POST /agent/plugins/gemini-image/capabilities/image.generate`

```bash
curl -s -X POST "http://127.0.0.1:$TIERWYN_LISTEN_PORT/agent/plugins/gemini-image/capabilities/image.generate" \
  -H "Authorization: Bearer <your spawn token>" \
  -H 'Content-Type: application/json' \
  -d '{"prompt":"a watercolour fox in a snowy forest","aspectRatio":"16:9"}'
```

Slow / large calls (Pro, 4K) need a longer client timeout:

```bash
curl --max-time 200 -s -X POST "http://127.0.0.1:$TIERWYN_LISTEN_PORT/agent/plugins/gemini-image/capabilities/image.generate" \
  -H "Authorization: Bearer <your spawn token>" \
  -H 'Content-Type: application/json' \
  -d '{"prompt":"a watercolour fox","model":"gemini-3-pro-image","imageSize":"4K"}'
```

For Pro / 4K, set your Bash tool timeout to `200000` so the tool call outlives the fetch.

## Input

| Field | Required | Notes |
| --- | --- | --- |
| `prompt` | yes | Text, max 8000 chars |
| `model` | no | Registry key or `-preview` alias; default `gemini-3.1-flash-image` |
| `aspectRatio` | no | Must be in the chosen model's ratio set |
| `imageSize` | no | `512` `1K` `2K` `4K` (case-insensitive); must be in the model's sizes; omitted ⇒ API default 1K |
| `inputImages` | no | Absolute paths inside **your** artifacts shard; PNG/JPEG/WEBP; ≤7 MB each, ≤14 MB total, ≤14 files |
| `thinkingLevel` | no | `minimal` or `high` (3.1 Flash / Lite only) |
| `googleSearch` | no | `true` enables Search grounding (Flash and Pro; not Lite) |
| `filename` | no | Bare basename `[A-Za-z0-9._-]`; `.png` appended then swapped to `.jpg` if the model returns JPEG; must not already exist |

## Models

| key | alias | sizes | ratios | max inputs | thinking | search | pick when |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `gemini-3.1-flash-image` (**default**) | `gemini-3.1-flash-image-preview` | 512 1K 2K 4K | standard + `1:4 4:1 1:8 8:1` | 14 | yes | yes | Default: fast, extreme ratios |
| `gemini-3.1-flash-lite-image` | — | 1K | standard | 14 | yes | no | Cheapest; 1K only |
| `gemini-3-pro-image` | `gemini-3-pro-image-preview` | 1K 2K 4K | standard | 14 | no | yes | Best quality and text rendering |

Standard ratios: `1:1 2:3 3:2 3:4 4:3 4:5 5:4 9:16 16:9 21:9`.

## Remix

To edit or remix an existing image, the source must sit inside **your** artifacts
shard: use the `path` from a previous generate, or `cp` the file in first. Then pass
it via `inputImages`. PNG/JPEG/WEBP, ≤7 MB each, ≤14 MB total, ≤14 files.

## Response and next step

```json
{"ok":true,"data":{"path":"/…/artifacts/<conversationId>/<name>.png","mime":"image/png","bytes":123456}}
```

Read the returned `path` with your file tool and show the image to the user.

## Limits and errors

One shared limit of **4 requests/min** covers all models; capability timeout is 180 s.
On 429 wait `retryAfter` seconds. Errors:

| Status | Meaning | Action |
| --- | --- | --- |
| 400 | `bad_input` — invalid arguments | Fix the args |
| 429 | `rate_limited` | Wait `retryAfter` |
| 503 | `credential_missing` | Tell the operator to set `GEMINI_API_KEY` in Settings → Plugins; don't retry |
| 502 | `upstream_error` (Gemini failure or safety block) | Rephrase the prompt or retry |
| 504 | `timeout` | Retry once with a longer client timeout |

## Forbidden

- Don't ask for or echo `GEMINI_API_KEY`.
- Don't call `generativelanguage.googleapis.com` directly — use this capability.
- Don't use the `gemini-image-remix` skill.
